# Инал Принц Тауэр — сайт жилого комплекса

Одностраничный сайт ЖК «Инал Принц Тауэр» (г. Гагра, ул. Абазгаа, 49).
Чистый HTML/CSS/JS без сборки — готов к публикации на GitHub Pages или любом статическом хостинге.

Дизайн-система «Чертёж»: тёплая бумага с миллиметровой сеткой, чернильный текст,
кипарисово-морской акцент, шрифты Unbounded / Manrope / IBM Plex Mono.

## Что внутри

- **Hero** с карточкой день/вечер и анимированными счётчиками
- **Интерактивная 3D-модель** дома (Three.js): ракурсы, режим день/ночь, мягкие тени, полноэкранный режим
- **Галерея** с лайтбоксом (стрелки + клавиатура)
- **Этажи** с интерактивной схемой дома (кликабельные этажи) и зумом планов
- **Покупка** — четыре шага сделки
- **Локация** со встроенной Яндекс-картой (ленивая загрузка)
- **FAQ** и **форма заявки** — сообщение формируется автоматически и открывается в WhatsApp
- Плавный скролл (Lenis), скролл-анимации (GSAP), поддержка `prefers-reduced-motion`
- SEO: мета-теги, Open Graph, schema.org (ApartmentComplex), robots.txt

## Настройка

### Номер WhatsApp (важно!)

Откройте `js/main.js` и в самом начале укажите номер отдела продаж
в международном формате без «+» и пробелов:

```js
var WHATSAPP_PHONE = '79991234567';
```

Пока номер пустой, WhatsApp предложит выбрать контакт вручную.

### Адрес сайта

Если сайт будет опубликован не на `https://invizvizion.github.io/Abh/`,
замените этот адрес в `index.html` (тег `link rel="canonical"`, мета-теги `og:url` и `og:image`,
блок `application/ld+json`).

## Публикация на GitHub Pages

1. GitHub → Settings → Pages
2. Source: **Deploy from a branch**, выберите ветку и папку `/ (root)`
3. Сайт появится по адресу `https://<владелец>.github.io/<репозиторий>/`

## Структура

```
index.html          — разметка всех секций
css/style.css       — дизайн-система и адаптив
js/main.js          — прелоадер, скролл, анимации, планировки, лайтбокс, форма
js/model.js         — 3D-вьювер (Three.js, ES-модуль)
assets/img/         — визуализации дома
assets/plans/       — поэтажные планы из проектного альбома
assets/models/      — 3D-модель здания (GLB)
```

Все зависимости (GSAP, Lenis, Three.js) и шрифты лежат локально — внешних CDN нет.
